# Lake_Early-Warning-System
SIGADANA (Sistem Informasi Gelombang dan Angin Danau) adalah sistem navigasi keselamatan pelayaran perairan darat berbasis web untuk Danau Toba. Sistem ini mengintegrasikan data cuaca real-time, estimasi gelombang, arus, dan peringatan dini guna mendukung keselamatan pelayaran di danau.
